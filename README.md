# Nkapweb — site de vente

Page statique de l'agence Nkapweb (sites internet payables par Orange Money, MTN Mobile Money, carte GIMAC et carte bancaire).

- `index.html` : la page complète, sans dépendance hors Google Fonts.
- `vercel.json` : en-têtes de sécurité et URLs propres.

Déploiement : importer ce dépôt dans Vercel (framework « Other »), puis ajouter le domaine nkapweb.com dans Settings → Domains.
